## Full Description (4000 chars max)

```
ArrowNook: Logic Puzzle

Clear the board — one arrow at a time.

Each puzzle is a grid of arrows pointing in different directions. Your goal is simple: find the arrow with a free path and slide it off the board. Clear every arrow to win.

Easy to learn, endlessly satisfying. ArrowNook is the perfect puzzle game for calm moments — whether you have 2 minutes or 2 hours.

🎯 HOW TO PLAY
• Tap an arrow to select it
• If its path ahead is clear, it slides off the board
• Find the right order to remove all arrows
• Clear the board to complete the level

🧩 FEATURES
• 10 hand-crafted levels to get you started
• Endless procedural puzzles — new challenges after the starter levels
• Smart hint system — stuck? Get a nudge, not a spoiler
• Clean, minimalist design — easy on the eyes
• Core puzzles work offline after install
• Ads are limited to banners and occasional level-transition interstitials
• Made with love in India 🇮🇳 by a solo developer

♾️ ENDLESS LEVELS
Once you finish the hand-crafted levels, ArrowNook generates brand-new puzzles. Each level number creates the same puzzle every time, so you can replay favorites.

💡 HINTS
Stuck on a tricky level? Use a hint to highlight the next arrow you can safely move. No spoilers — just enough help to get unstuck.

ArrowNook: Logic Puzzle — made with ❤️ in India by Anupam Pradhan, a solo indie developer.
```
